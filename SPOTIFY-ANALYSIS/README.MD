# Spotify Music Analysis

## Project Overview
This project focuses on analyzing Spotify music data using Microsoft Excel.

## Objectives
- Analyze music and track performance
- Identify trends and patterns
- Generate meaningful insights
- Present findings through clear analysis and visualization

## Tools Used
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization

## Dataset
Spotify music dataset containing track and music-related information.

## Skills Demonstrated
Excel | Data Analysis | Data Visualization | Business Analysis
