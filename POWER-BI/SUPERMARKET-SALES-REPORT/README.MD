# Supermarket Sales Report

## Project Overview
This project presents an interactive supermarket sales dashboard created using Microsoft Power BI.

## Objectives
- Analyze sales and profit performance
- Identify high-performing categories and sub-categories
- Analyze regional and state-wise performance
- Understand customer and order trends
- Present key business insights through an interactive dashboard

## Tools Used
- Microsoft Power BI
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization

## Skills Demonstrated
Power BI | DAX | Data Analysis | Data Visualization | Business Intelligence
