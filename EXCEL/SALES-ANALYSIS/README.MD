# Excel Sales Analysis

## Project Overview
This project focuses on analyzing supermarket sales data using Microsoft Excel.

## Objectives
- Analyze sales performance
- Understand product and category performance
- Identify useful business insights
- Present data in a clear and structured format

## Tools Used
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization

## Dataset
Supermarket sales dataset containing transaction and sales-related information.
